# Newsagent
# 🚀 YouTube + Instagram News Agent
### Automated breaking-news shorts — posted within 30 minutes of a story breaking

> **Platform:** Works on Windows, macOS, and Linux.
> **Windows users:** Use the `.bat` / `.ps1` scripts in `scripts/`. Ignore the `.sh` files.

---

## What This Does

| Step | What happens | Your effort |
|---|---|---|
| 📡 Monitor | Watches BBC, Reuters, NewsAPI, Reddit every 90 seconds | Zero |
| ✍️ Write | Claude AI writes a 27–34 second viral script | Zero |
| 🎬 Assemble | FFmpeg builds the video with b-roll + subtitles | Zero |
| 📤 Post | Uploads to YouTube Shorts + Instagram Reels | Zero |
| 📅 Streak | Injects "Day X" counter into every title + caption | Zero |
| 📋 Briefing | Sends you an 8am daily plan + comment intelligence | 1 hour |

**You spend 1 hour/day. The agent handles everything else.**
